# TREE COMPANY - Платформа для заказа и управления услугами

Прогрессивное веб-приложение (PWA) для бизнеса по профессиональной установке дверей и плинтусов. Проект включает в себя клиентскую часть для заказа услуг, панель администратора для управления бизнесом и интерфейс для сотрудников.

## 🏗 Структура проекта

Архитектура проекта разделена на независимые модули для удобства масштабирования и поддержки. В каждом приложении строго соблюдается модульный подход: HTML, CSS и JavaScript вынесены в отдельные файлы.

*   `/tree-client` — **Клиентское приложение (PWA):**
    *   Главная страница с услугами.
    *   Калькулятор стоимости и форма оформления заказа.
    *   Форма подачи заявки на вакансию (мастера, помощники).
    *   Поддержка установки на главный экран смартфона (iOS/Android) с пользовательским SVG-логотипом.
*   `/tree-admin` — **Панель администратора:**
    *   Управление ценами и прайс-листами.
    *   Управление базой сотрудников и заявок.
    *   Дашборд со статистикой (счетчики новых, выполняемых и завершенных заказов).
*   `/tree-employee` — **Приложение для сотрудников:**
    *   Просмотр доступных и текущих заказов.
*   `/api` — **Serverless-функции (Backend):**
    *   Обработка POST-запросов от клиентских форм.
    *   Интеграция с базой данных / Telegram для маршрутизации заявок.

## 🚀 Технологический стек

*   **Frontend:** HTML5, CSS3, Vanilla JavaScript.
*   **Локализация:** Встроенная мультиязычность (Армянский, Русский, Английский) с переключением через флаги.
*   **Дизайн:** Адаптивный Glassmorphism, поддержка светлой и темной тем.
*   **Backend & Hosting:** Vercel (Serverless Functions).

## ⚙️ Установка и Деплой

Проект настроен для автоматического развертывания через GitHub на Vercel.

1. Запушьте все папки проекта в репозиторий GitHub.
2. В панели управления Vercel создайте новый проект и импортируйте этот репозиторий.
3. Vercel автоматически распознает папку `/api` и развернет серверные функции.
4. (Опционально) Настройте переменные окружения (Environment Variables) в Vercel для API-ключей базы данных или Telegram бота.
